# Mac クリーン再インストール計画

## 目的

Macを定期的に初期化し、不要なアプリ、設定、キャッシュ、履歴を持ち込まずに、必要な環境だけを再構築する。

この計画では、Time Machineや移行アシスタントによる一括移行を使用しない。初期化前に必要性を1項目ずつ判断して退避し、初期化後も必要になったものだけを復元する。

## 運用方針

- Macは「新しいMac」としてセットアップする
- ホームディレクトリやアプリデータを丸ごと復元しない
- Gitやクラウドから取得できるデータは、ローカルコピーを持ち込まずに再取得する
- 認証情報は、可能な限り新環境で再ログインまたは再発行する
- 再取得が難しいデータだけを個別に退避する
- macOS設定とdotfilesは、このリポジトリのnix-darwinとchezmoiから復元する
- アプリ、CLI、言語ランタイム、エディタ拡張は、必要性を再判断してから導入する
- キャッシュ、ログ、ビルド成果物、再生成可能な依存関係は復元しない
- 退避したデータは、新環境の動作確認が終わるまで削除しない

## この計画の使い方

初期化を行うたびに、次の実施情報を記録する。

```text
実施日:
対象Mac:
現在のmacOS:
再インストールするmacOS:
退避先:
初期化の目的:
```

各項目は、次のいずれかに分類する。

### 必ず復元する

再取得できないデータ、現在も使用しているデータ、秘密鍵など。

### 必要になったら復元する

過去の履歴、成果物、カスタム設定など。初期化後すぐには戻さず、必要性が確認できた時点で復元する。

### 復元しない

キャッシュ、ログ、ビルド成果物、依存関係、現在使っていないアプリや設定。

判断に迷うものは、暗号化した退避先へ保管する。ただし、新環境にはすぐに戻さない。

## 完了条件

- 必要な作業データを新環境から利用できる
- GitHubへのclone、commit、pushができる
- このリポジトリからmacOS設定とdotfilesを適用できる
- 使用を継続するプロジェクトの開発環境が動作する
- 必要なアプリだけがインストールされている
- 旧環境のキャッシュ、ログ、不要な設定を持ち込んでいない
- 退避対象と復元結果を項目ごとに確認している

## フェーズ1: 退避先の準備

一括バックアップは作成しないが、選択したファイルの保存先は暗号化する。

構成例:

```text
Mac-clean-reinstall/
├── credentials/
├── documents/
├── project-local-data/
├── custom-tools/
├── codex-selected/
├── app-settings-selected/
└── inventories/
```

### 退避時の確認

- [ ] 退避先が暗号化されている
- [ ] 退避先の空き容量を確認した
- [ ] コピー先のファイルを実際に開いた
- [ ] 元ファイルとコピー先のファイルサイズを比較した
- [ ] ディレクトリの場合はファイル数を比較した
- [ ] 重要なファイルはSHA-256チェックサムを比較した

同じ物理ディスク内の別フォルダは、元のMacが故障した場合の保護にならない。退避先には外部ストレージまたは信頼できるクラウドストレージを使用する。

- [ ] 必要なブランチとタグがリモートに存在する

### Git管理外データ

プロジェクトごとに、次の候補を確認する。

- `.env`
- `.env.local`
- APIキーを含む設定
- ローカルデータベース
- 署名鍵
- 証明書
- アプリ配布用の設定
- ローカルで作成したテストデータ
- Gitのignore対象になっている成果物

チェックリスト:

- [ ] Git管理外ファイルをプロジェクトごとに確認した
- [ ] 再取得できないファイルだけを選んだ
- [ ] 秘密情報を暗号化した退避先へコピーした
- [ ] ファイルの用途と復元先を記録した
- [ ] コピー先から実際に開いて確認した

依存関係やビルド成果物は退避しない。

- `node_modules`
- `Pods`
- `.dart_tool`
- `build`
- `dist`
- `.next`

- パッケージマネージャーのキャッシュ

### 確認候補

- 添付ファイル
- 過去のセッション

### 推奨する扱い

| 項目 | 方針 |
| --- | --- |
| カスタムスキル | 継続利用するものだけ個別退避 |
| カスタムペット | 継続利用するものだけ個別退避 |
| 生成画像 | 成果物として必要な画像だけ退避 |
| 添付ファイル | 元ファイルがほかにないものだけ退避 |
| セッション | 必要な過去タスクがある場合のみ保管用に退避 |
| ルール、メモリ | 内容を確認して必要なものだけ退避 |
| `config.toml` | 参考用に保管し、新環境では差分を確認して必要部分だけ反映 |
| `auth.json` | 復元せず再ログイン |
| プラグイン | 復元せず必要なものだけ再インストール |
| キャッシュ、ログ、一時ファイル | 復元しない |
| Computer Useのランタイム | 復元しない |

## 退避データの整理

新環境を一定期間使用し、必要なデータが揃っていることを確認してから退避データを整理する。

- [ ] 復元した項目を記録した
- [ ] 復元しなかった項目を再確認した
- [ ] 今後も保管する成果物を恒久保存先へ移した
- [ ] 不要なキャッシュやログを削除対象として確認した
- [ ] 秘密鍵や認証情報を安全な保管場所へ移した
- [ ] 次回に備えて、この計画書の不足点を更新した

退避データの削除は、必要なデータが新環境と恒久保存先の両方で確認できた後に行う。

## 継続的な改善

初期化のたびに手作業で復元した項目を記録し、次の基準で管理方法を見直す。

- 毎回必要になる設定はchezmoiまたはnix-darwinで管理する
- 毎回必要になるCLIやアプリは宣言管理へ移す
- 毎回必要になるエディタ拡張は再インストール手順を追加する
- 再取得できるデータは退避対象から外す
- 認証情報と秘密情報は設定リポジトリに含めない
- 一時的にしか使わないものは宣言管理へ追加しない

この文書は、特定時点のインストール状況を記録する台帳ではなく、クリーン再インストール時の判断と確認を行うための継続利用可能な手順書として維持する。
